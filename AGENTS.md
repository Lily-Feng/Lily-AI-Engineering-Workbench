# Lily’s AI Workbench — Agent Guide

An Astro Starlight site, built the same way as the Reinforcement Learning site.
See the README’s “Website” section for where each page lives and how to run it.

## Review before commit

Lily verifies every change herself before it reaches GitHub.

1. **Do not commit or push until Lily has reviewed the change.** Pushing is a
   separate step that needs her explicit go-ahead, even after she approves a
   commit.
2. **When the work is finished, launch a local view for review**
   (`npm run dev`, then http://localhost:4321/Lily-AI-Engineering-Workbench/),
   give her the URL, and list what to check. Stop there.

Run `npm run check` and `npm run build` before handing over; both must pass.
