One framework, eighteen ways in. Each module has numbered topics, interview
questions, and a hands-on project in its
[source chapter](https://github.com/Lily-Feng/Lily-AI-Engineering-Workbench/tree/main/modules).
`P0` means core practice and `P1` deeper systems work. Interactive explanations
are built one topic at a time; the first is
[attention, made visible](/Lily-AI-Engineering-Workbench/library/attention/).
